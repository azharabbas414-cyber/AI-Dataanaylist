# InsightAI

AI-Powered Data Analytics Platform built with Python and Streamlit.

## Current milestone
- Modern Streamlit shell
- CSV/Excel upload
- Dataset preview
- Basic data-quality/profile metrics
- Sample sales dataset
- Modular pages ready for analytics and AI features

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
